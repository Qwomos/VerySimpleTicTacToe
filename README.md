# VerySimpleTicTacToe
Simple game of Tic tac toe written in C# with Raylib-cs and .NET

## Prerequisite

### Install .NET 10 SDK
Go to https://dotnet.microsoft.com/en-us/download/dotnet/10.0 and follow instructions according your operating system.

## Documentation

### C# and .NET
https://dotnet.microsoft.com/en-us/learn

### Raylib (C++)
https://www.raylib.com/

### Raylib-cs Repo
https://github.com/raylib-cs/raylib-cs

## Lunch the App
1. Move to src folder
```batch
cd src
```

2. Start the game with **.NET**
```batch
dotnet run
```
**or**
```batch
dotnet watch
```
