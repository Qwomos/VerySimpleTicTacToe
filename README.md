# VerySimpleTicTacToe
Simple game of Tic tac toe using Raylib-cs. For non-commercial use only.

## Prerequisite

### Install .NET 10 SDK
Go to https://dotnet.microsoft.com/en-us/download/dotnet/10.0 and follow instructions according your operating system.

## Lunch the App
1. Move to src folder
```batch
cd src
```

2. Start the game with **.NET**
```batch
dotnet run
```
**or**
```batch
dotnet watch
```
